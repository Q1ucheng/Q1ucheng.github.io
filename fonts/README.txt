字体文件说明
============

本目录下的 woff2 都是 latin 子集（只包含页面实际用到的字符），单个文件 14–23 KB，
由 @fontsource 的官方构建生成，随页面一起分发，不再依赖 Google Fonts。

  官方页面：https://fonts.google.com/specimen/Outfit
  文件来源：https://www.npmjs.com/package/@fontsource/outfit

Playfair Display（姓名所用的装饰衬线体）

图标
====
页面里的 GitHub / WeChat / Zhihu 图标来自 Simple Icons（CC0 1.0），
邮件、太阳、月亮、省略号图标来自 Lucide（ISC），均已内联为页面中的 <svg>，
不再通过 CDN 加载 Font Awesome。
  https://simpleicons.org/
  https://lucide.dev/
